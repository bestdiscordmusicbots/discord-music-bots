## How to Add a Music Bot to Discord
Adding a music bot to your Discord server takes less than a minute:
1. Go to the bot's official website (linked above for each bot).
2. Click the "Add to Discord" or "Invite" button.
3. Log in to your Discord account if prompted.
4. Select the server you want to add the bot to from the dropdown.
5. Review the permissions the bot requests and click Authorize.
6. Complete any CAPTCHA if shown.
7. The bot will appear in your server's member list and is ready to use.
Most music bots require "Connect" and "Speak" permissions to join voice channels. Some also need "Send Messages" and "Embed Links" to display now-playing cards.

## Common Music Bot Commands
Most Discord music bots share a similar set of slash commands:
| Command | Action |
|---|---|
| `/play [song or URL]` | Search and play a track or playlist |
| `/pause` | Pause the current track |
| `/resume` | Resume playback |
| `/skip` | Skip to the next track |
| `/stop` | Stop playback and clear the queue |
| `/queue` | View the current queue |
| `/nowplaying` | Show the currently playing track |
| `/loop` | Toggle loop mode (track or queue) |
| `/shuffle` | Shuffle the queue |
| `/volume [1-100]` | Adjust playback volume |
| `/lyrics` | Show lyrics for the current track |
| `/24-7` | Enable 24/7 mode (stays in voice channel) |
| `/filter` | Apply audio filters |
| `/disconnect` | Remove the bot from the voice channel |
Exact command names may vary between bots. Check each bot's documentation for the full command list.

## What to Look for in a Discord Music Bot
Not every music bot works the same way. Here are the things worth checking before you add one:
**Source support** — Make sure the bot can play from the platforms your server uses. YouTube is standard, but Spotify, Apple Music, Tidal, and SoundCloud support varies by bot.
**Audio quality** — Look for bots that mention bitrate control or regional server nodes. These signal better infrastructure.
**Free tier limits** — Some bots restrict queue length, audio quality, or filter access on the free plan. The bots listed here all have generous free tiers.
**Commands** — Slash commands are now standard on Discord. Avoid bots that rely only on prefix-based commands as Discord has phased out message intent for public bots.
**Uptime and reliability** — Check the bot's status page or community reviews. A music bot that goes offline frequently is not worth adding regardless of features.
**Moderation controls** — DJ roles, vote-to-skip, and channel restrictions matter for active servers where multiple people use the bot at once.
